stubs. This avoided starting a GitHub Actions run. The compiler was Debian
`g++ 14.2.0`. SDL2 development tools and the Arduino toolchain were not installed.

expected `PASS` line and exit status 0. The touch harness used the sketch
generated by `tools/emu/genproto.py` and linked the real firmware sources to the
host stubs.

## Reproduction commands

Run from the repository root. `/tmp/tamapoke-check` is only an output directory.

```sh
mkdir -p /tmp/tamapoke-check
CORE='gbsynth.cpp pet.cpp i18n.cpp party.cpp battle.cpp link.cpp save.cpp chess.cpp'

g++ -std=c++17 -O1 -w -Itools/emu -I. \
  -DSPRITE_DIR='"tools/sdcard/mons"' \
  -o /tmp/tamapoke-check/battle tools/emu/tests/battle_test.cpp $CORE
/tmp/tamapoke-check/battle

g++ -std=c++17 -O1 -w -Itools/emu -I. \
  -DSPRITE_DIR='"tools/sdcard/mons"' \
  -o /tmp/tamapoke-check/save tools/emu/tests/save_test.cpp $CORE
/tmp/tamapoke-check/save

(cd tools/emu && python3 genproto.py ../../TamaPoke.ino && \
  { echo '#include "proto.h"'; cat ../../TamaPoke.ino; } > sketch.cpp)
g++ -std=c++17 -O1 -w -Itools/emu -I. \
  -DSPRITE_DIR='"tools/sdcard/mons"' \
  -o /tmp/tamapoke-check/touch tools/emu/tests/touch_test.cpp $CORE \
  tools/emu/sketch.cpp tools/emu/host_impl.cpp tools/emu/font.cpp tools/emu/clock.cpp
/tmp/tamapoke-check/touch

g++ -std=c++17 -O1 -w -Itools/emu -I. \
  -o /tmp/tamapoke-check/i18n tools/emu/tests/i18n_test.cpp i18n.cpp
/tmp/tamapoke-check/i18n
```

## Not verified on this head

- The complete emulator suite was not run. `sdl2-config` is unavailable, so
  `tools/emu/tests/run.sh` cannot build its emulator prerequisite.
- No ESP32-S3 firmware compile was run. I downloaded Arduino CLI 1.6.0, but its
  pinned core and libraries could not be installed: outbound DNS for the
  Arduino package indexes and `raw.githubusercontent.com` is unavailable here.
  Therefore ESP32 core 3.3.10 and the workflow-pinned libraries are not present.
- The pinned firmware build recorded in the earlier handoff is for commit
  `489a3fd9cba2adabb047a208526b3a5961efbbbe`, before the wild battle and item
  inventory changes. It does not verify this head.
- No GitHub Actions workflow, hardware, installer, merge or publication was
  used for these checks.
