# Replacement character art gate

Owner rejects the geometric Bulbasaur pilot. Do not use it for release or extend its style to other species.

Candidates for evaluation:
- https://agora.community/store/assets?resource=bulbasaur — textured Maya rig, Santiago Calle and Juan Giraldo, study/practice/community projects, no commercial use; confirm permitted export and distribution.
- https://sketchfab.com/3d-models/bulbasaur-pokemon-animated-d2a9a7962613438387880a195cd8a1df — prozip animated model, uploader lists CC Attribution; underlying franchise rights remain separate.
- https://github.com/huanghdm88/pokemon-3d-models — GLB collection with per-model author credits and embedded animations; audit individual entries, not repository MIT alone. Avoid procedural models.
- https://github.com/Pokemon-3D-api/api-server/blob/main/docs/COPYRIGHT.md — explicitly excludes Pokémon IP from MIT code license.

Use existing licensed/authorized local source renders first. No new third-party assets in public repository or installer without permission review. Require whole-character textured render, natural canonical anatomy, actual walking clip, consistent framing and ground contact. Owner visual approval before broad rollout. Retain original PMD artwork for unsupported actions and shiny variants. Offline TPK2 raster export; no runtime 3D.

## November 24 source review

- The [Pokémon press asset terms](https://press.pokemon.com/en/Assets-Use-Terms)
  cover editorial or informational use and bar derivative works. Official
  art available through a sprite mirror does not grant a game-use license.
- The Agora rig lists animation study, practice and community creation.
  The Sketchfab entry lists attribution terms for the upload. Neither
  listing substantiates permission for the underlying Pokémon design in
  distributed game renders.
- Continue with the current species, action and shiny assets while a source
  with documented authorization is pending. Start with one Bulbasaur
  idle and walk pilot. Record the model, textures, motions and render
  permissions before evaluating the result in the living room and battle
  emulator. Check actual contact, silhouette, palette and circular clipping
  before extending the same workflow to Charmander, Squirtle and Pikachu.
